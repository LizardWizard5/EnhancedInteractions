# Description
The goal of this mod is to create Vanilla friendly interactions between blocks and items. 

This mod doesn't add any new mobs/blocks/items.

# Current Features

## Dispensers can empty and fill cauldrons using buckets
![Three cauldrons next to each other with Dispensers filling and emptying them with Powdered Snow, Lava and Water](https://i.imgur.com/QAidKTQ.gif)


## Dispensers and Hoppers can fully automate farms
* Dispensers can plant crops when facing farmland block
* Dispensers can apply bonemeal to any bonemealable block it's facing
* Hoppers can auot harvest and replant crops

![Dispenser Facing farmland, Hopper under farmland, Dispenser ontop of other Dispenser. The dispenser facing farmland is planting wheat seeds, the other dispenser is applying bonemeal, and the hopper is harvesting and then replanting the wheat](https://i.imgur.com/TjNpOu0.gif)

## Dispensers can plant Netherwart on facing Soulsand
* Hoppers can auto harvest and replant these aswell

![Dispenser facing Soulsand and planting Netherwart](https://i.imgur.com/dNvXe2i.gif)
## Dispensers can now plant saplings and fungus
* Dispensers can bone meal these aswell

![Dispenser planting a sapling on dirt](https://i.imgur.com/4EVflmE.gif)
![Dispenser planting fungus on nylium](https://i.imgur.com/F2oEOef.gif)
